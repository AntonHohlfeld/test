# Product Roadmap

## Phase 0: Product Definition (Current)

- Define visual language and widget hierarchy.
- Lock architecture and performance SLAs.
- Draft telemetry contracts.

## Phase 1: Foundation

- Scaffold monorepo, CI, linting, formatting, test harness.
- Implement desktop host with tray, settings, and window manager.
- Implement bridge with mock telemetry replay.

## Phase 2: MVP Widgets

- Relative
- Standings
- Input telemetry
- Fuel + stint
- Alerts

## Phase 3: Competitive Features

- Advanced race strategy module.
- Track map + incident overlays.
- Team session sharing (optional online mode).
- Streamer scene presets.

## Phase 4: Quality + Distribution

- Installer + auto-update channel.
- Crash reporting and diagnostics package export.
- Documentation site + widget SDK docs.

## Definition of Done (MVP)

- Supports full race sessions without manual restarts.
- Stable telemetry at target latency for > 90 minutes.
- Widget presets can be exported/imported.
- Clear onboarding in under 5 minutes.
